# 内置云端生成式编辑（本地定制版）

贡献说明：基于云端 PR #2878（`0660b25fdf42aebfdbb880bd1459ce32e91914c1`）的模块设计，加入自定义端点和生成式扩展。保留原贡献者的设计归属；不含 Adobe Firefly。

## 配置

在 Edit → Preferences → Integrations → Generative AI Settings 中配置。首次运行默认关闭，不读取其他软件的 API Key，不自动发送图像。

- **OpenAI-compatible Images**：Base URL 填写至 `/v1` 或供应商的等价 API 前缀。请求发送到 `/images/edits`，使用 multipart 图像和透明蒙版，要求服务返回 `data[0].b64_json`。仅聊天兼容不能满足要求，URL-only 返回暂不支持。
- **Gemini-compatible Images**：Base URL 填写至 `/v1beta` 或等价前缀。请求使用 `/models/<model>:generateContent`，发送原图、白色代表修改的参考蒙版及编辑说明，并读取返回的 inlineData 图像。
- **Google Gemini (Interactions)**：保留原 PR 的接口适配，模型和该接口当前可用性仍需用实际账号验证。

模型名称可以手动填写；必须是供应商实际支持的图像编辑模型。超时可设为 30–600 秒。保存设置只检查本地配置并构建 provider，不验证远端账号、额度或生成能力。

API Key 存入 Windows Credential Manager 的 `ai.storyteller.photocraft.genai.v1` 服务。自定义协议按协议和规范化 Base URL 分开存储。Key 不写入偏好文件、文档、UI inspection、日志或导出。更改服务地址后需要提供该地址对应的 Key。删除 Key 是即时操作。

## 填充与扩图

配置成功后，Edit 菜单显示 Generative Fill 和 Generative Expand。

- 填充：圈选区域，输入描述。留空时请求移除选区内容并延续周围图像。新建结果图层，以原选区作为蒙版；一次撤销移除结果。
- 扩图：输入左、上、右、下增加的像素。后台请求成功后，同时调整画布并插入新增区域的蒙版图层。原图随左、上扩展平移，一次撤销恢复画布与图层；失败不扩大画布。当前入口是内置对话框，尚未接入 Crop 工具拖拽。

状态栏显示后台进度、取消和错误；成功后显示服务、模型、耗时。结果始终是真实 provider 返回的图像，不使用本地模板冒充模型结果。

## 限制与验收

- 上传选区及周围必要上下文、蒙版和提示词，发送到用户填写的 HTTPS 端点；服务商可能计费。最长边压缩至 2048，结果缩放回目标区域。大区域可能损失细节，生成内容质量取决于模型。
- 扩图每边最多增加 4096 像素，结果画布最长边 8192、总面积 3200 万像素。
- 当前一次生成一个结果，保留为新图层。尚无多候选缩略图切换，也没有独立远端连接测试按钮。
- 取消会阻止结果写回，不保证立即中断已发送的 HTTP 请求或停止云端计费。
- 保留原分支的自动化上传边界：control/MCP 不允许触发填充或扩图上传；实际使用需在软件中点击。
- 假 transport、模拟 provider 和编译不等于真实云端验收。用户配置 API 后仍需验证自己的端点、模型、费用、接缝效果与网络环境。

## 升级与回退

定制版放在独立目录，分发时附 `portable.txt`，设置保存在该目录的 PhotoCraftData。不要用定制 EXE 覆盖 Program Files 下的官方安装。官方 Launcher 更新只更新官方版本，不更新本定制版。

升级必须固定新的上游 SHA，在新的本地分支重放补丁，检查上游是否已出现同名 AI 功能；重点比较命令注册、Session、菜单、设置页、后台任务、自动化授权、依赖层级。先运行 provider 合同、选区与扩图、撤销与失败、凭据隔离和 UI 测试，再验证独立程序与实际 API。不能承诺未来版本免修改兼容。

回退时保留当前目录和配置备份，重新启动上一版定制目录或原官方版。不要将真实 API Key 放进源码、测试或发布归档。

填充的选区及周围上下文同样限制为最长边 8192、总面积 3200 万像素；超过时请缩小选区。这是写回结果的内存保护，与上传最长边 2048 的限制分别生效。
